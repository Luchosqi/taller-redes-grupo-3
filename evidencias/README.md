# Evidencias

Guardar capturas obtenidas por el Grupo 3 dentro de la carpeta temática que corresponda. Esta estructura es provisional y debe cotejarse con la pauta oficial.

## Criterios

- Preferir PNG legibles, con el contexto necesario para identificar la prueba.
- Nombrar archivos con un orden y tema claros, por ejemplo `03-dns-consulta-a-001.png`.
- No capturar contraseñas, llaves, tokens, datos de autenticación ni información personal innecesaria.
- Conservar la salida o configuración que demuestre el resultado, no solo un comando sin contexto.
- En el informe, explicar qué acción/configuración se ve, qué objetivo cumple y qué resultado o requisito respalda.
- Elegir capturas representativas; no es necesario guardar una captura por cada comando.
